# Version 26.10.1.2

- Fixed files sent by Perla never arriving in the web companion. Two independent defects stacked: the MCP servers were configured with `env`, but OpenCode's `McpLocalConfig` spells that key `environment` (`env` belongs to the `lsp` config and is silently ignored), so `PERLA_TIER` never reached the file tool and it defaulted to 0 — the daemon therefore never recorded a staged file; and the daemon's staged-file fallback was gated on finding a `send_file` tool part in OpenCode's reply, which that server no longer includes (it returns only the final step's parts), so the fallback could never fire either. A send would stage the file and report its id to the user while the web UI received `"file": null`. All five MCP servers on both tiers were affected; the other variables were only surviving on their defaults.

- Added GFM pipe-table rendering to the web companion: real `<table>` markup with `:---` / `:---:` / `---:` alignment honoured, inline formatting and `\|` escapes working inside cells, cell text escaped like everywhere else, and a horizontally scrolling wrapper so a wide table stays readable on a phone. A table inside a code fence is still code.
- TTS now understands tables instead of saying "pipe". A table of up to 6 rows is read out (header, then each row as comma-separated values); a larger one is announced as "A table with 12 rows and 3 columns" rather than read cell by cell. Markdown inside a cell is still flattened, so a link in a cell speaks its label, not its URL.

- Perla's text mode stopped sounding like a chatbot. The persona's "Text Mode (Full Breakdown)" section told her to "go full Character.AI human mode" with asterisks for micro-expressions and to frame answers as a live debate, which is what produced long, heavily-formatted replies. It now defaults to the same 1-3 sentences as voice, treats structure as earned (lists for real 3+ item lists, tables for genuinely comparable data, headers only when depth was asked for), drops the stage-direction asterisks, and bans closing summaries and opener padding. Opinions and the rhetorical lean are unchanged - only the performance is gone. Asking for "the full breakdown" still gets a thorough structured answer; length is a response to being asked rather than the default. Tier 1 got the same rule.
